# MachineProof — ETHGlobal Tokyo 2026

MachineProof is a trust infrastructure for global used industrial machinery transactions.

This repository contains the open-source blockchain components developed for ETHGlobal Tokyo 2026.

## Existing Product

MachineProof existed before ETHGlobal Tokyo 2026 as an early-stage product for:

- machine identity and digital passports
- equipment information
- provenance records
- trade documentation and workflows

The existing commercial application is maintained separately.

## ETHGlobal Tokyo 2026 Scope

The following components are planned to be developed during ETHGlobal Tokyo 2026:

- Onchain Machine Identity
- Inspection Attestations
- Chain of Custody
- Conditional Settlement / Escrow
- AI Agent → Ethereum integration

## Pre-Hackathon Status

No ETHGlobal-specific blockchain implementation has been completed yet.
